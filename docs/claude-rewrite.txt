3. Rewrite Plan for CLAUDE.md
Anchor architecture in current code: Describe backend as FastAPI APIs plus SPA fallback in app/main.py; avoid any template-serving language. Point contributors to app/routes/ modules for API work and to Vite output at app/static/dist/.
Front-end directives: Mandate Vue 3 + Vite in build/frontend/, UnoCSS usage (scoped utilities + uno.config.js), Naive UI components only, and routing through src/router/index.js with history mode.
Styling guidance: Replace all main.css/legacy.css references with build/frontend/src/styles/global.css, UnoCSS shortcuts, and component-scoped styles; note that there is no /static/css directory.
Shared logic: Require new logic to live in composables under build/frontend/src/composables/ (including composables/naive), and prefer path aliases defined in vite.config.js (@components, @views, @composables).
Backend expectations: Emphasize API-only surface, no HTML responses except SPA fallback, and removal of unused template dependencies (e.g., jinja2).
Legacy asset policy: Flag app/static/js/* as legacy; instruct agents not to extend them and to migrate any remaining dependencies into Vue composables before deletion.
Testing/ops pointers: Reference existing pytest suite under app/tests/ and Vite build/test scripts; keep Docker-first workflow but drop all mentions of Flask-era tooling.
