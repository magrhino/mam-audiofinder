# BACKEND.md - ShelfArr FastAPI Service

This document describes the ShelfArr backend architecture after the migration to a Vue SPA + FastAPI stack. The service now serves only API endpoints and the SPA index—no HTML templates or Jinja routes remain.

---

## Architecture & Routing
- **Bootstrap:** `app/main.py` configures logging, initializes databases, mounts `/static`, and builds the FastAPI app object (legacy title string will be renamed to ShelfArr in code). Routers are aggregated in `app/routes/__init__.py`.
- **Static assets:** `/static` mounts `app/static/`, which includes the Vite build output in `app/static/dist/` (generated by `build/frontend/`).
- **SPA fallback:** A catch-all route in `app/main.py` (`@app.get("/{full_path:path}")`) returns `static/dist/index.html` so Vue Router history mode works for deep links and refreshes.
- **API-only surface:** All routes under `app/routes/` return JSON or file responses—no HTML responders remain. Primary modules: `search.py`, `history.py`, `import_route.py`, `qbittorrent.py`, `covers_route.py`, `logs_route.py`, `series.py`, `showcase.py`, and `basic.py` (`/health`, `/config`).
- **Fallback precedence:** API routers are registered before the SPA fallback, guaranteeing API calls bypass the catch-all and return proper JSON responses.

### Endpoint Map (by module)
- `app/routes/basic.py` → `/health`, `/config`
- `app/routes/search.py` → `/search`
- `app/routes/history.py` → `/history`
- `app/routes/import_route.py` → `/import`
- `app/routes/qbittorrent.py` → `/qb`
- `app/routes/covers_route.py` → `/covers`
- `app/routes/logs_route.py` → `/logs`
- `app/routes/showcase.py` → `/showcase`
- `app/routes/series.py` → `/series`

## SPA Fallback & Asset Serving
- **Index delivery:** Any GET request not handled by the routers returns `FileResponse("static/dist/index.html")` from `app/main.py`.
- **Asset pathing:** Vite builds to `app/static/dist/` with `base: "/static/dist/"` (see `build/frontend/vite.config.js`). FastAPI’s `/static` mount exposes JS/CSS/assets at `/static/dist/...`.
- **Vue Router:** Client-side history mode owns navigation; unknown SPA paths are redirected client-side via the catch-all route defined in `build/frontend/src/router/index.js`.

## API + Auxiliary Services
- **Search & add:** `/search` queries MAM and returns results with library flags; `/qb` handles torrent submission with category/post-import options.
- **History & imports:** `/history` surfaces past actions; `/import` runs linking/copy/move flows, flattening multi-disc sets when `FLATTEN_DISCS=true`, and triggers verification.
- **Audiobookshelf integration:** ABS client lives in `abs_client.py`; verification and metadata enrichment happen during imports and cover loads.
- **Cover loading:** `/covers` streams cover files from the cover cache; the cache limits are governed by `MAX_COVERS_SIZE_MB`.
- **Series discovery:** `/series` integrates Hardcover metadata for series exploration.
- **Description service:** Description fetching logic remains available under auxiliary services (e.g., `description_service.py`) and should be documented as part of backend subsystems rather than the sole focus.

## Startup Dependencies & Expectations
- **FastAPI runtime only:** Backend assumes a built SPA in `app/static/dist/`; missing assets will result in the fallback returning a 404. Run `npm run build` in `build/frontend/` before container/image builds.
- **Removed pieces:** Jinja templates (`app/templates`) and `app/static/pages` were deleted per `docs/jinja_migration_changes.md`. No HTML template rendering is expected.
- **CSS pipeline:** Backend serves the compiled `app/static/css/main.css` and `app/static/css/legacy.css` files. Vue-specific global styles live in `build/frontend/src/styles/global.css` and are bundled into the SPA; template-specific overrides no longer exist.

## Configuration Notes
- **Core behavior:** `IMPORT_MODE`, `FLATTEN_DISCS`, and ABS/Hardcover settings (`ABS_BASE_URL`, `ABS_API_KEY`, `HARDCOVER_SERIES_LIMIT`) shape import flows, verification, and series discovery.
- **Environment alignment:** `.env` governs container mount points (`MEDIA_ROOT`, `DATA_DIR`, `DL_DIR`, `LIB_DIR`) and logging (`LOG_MAX_MB`, `LOG_MAX_FILES`). Ensure volumes match container paths for import correctness.
- **qBittorrent defaults:** `QB_CATEGORY` and `QB_POSTIMPORT_CATEGORY` control torrent categorization; defaults should align with the SPA labels and Docker compose settings.

## Migration Status & Cleanup
- FastAPI fully replaced Flask/Jinja; only APIs plus the SPA index are served.
- Legacy template references, mentions of `app/templates`, and HTML route handlers are removed. Future documentation updates should keep the FastAPI + SPA split explicit.
- See `docs/jinja_migration_changes.md` and `docs/css_refactoring_summary.md` for the authoritative history of template removal, SPA fallback behavior, and CSS layering.
